# OpenTDP
OpenTDP is an open specification for Technical Data Packages. It defines the TDP file structure, metadata schema and tooling ecosystem for interoperable technical data exchange.
OpenTDP

OpenTDP is an open specification for Technical Data Packages (TDPs), designed to enable the broader, safer and more efficient use of advanced manufacturing methods — including additive manufacturing (3D printing).

TDP files act as manufacturing recipes that encapsulate all essential technical information required to produce a part. By standardizing how this information is packaged, OpenTDP helps ensure the availability of critical spare parts, strengthens supply‑chain resilience, and supports sustainable manufacturing practices.

OpenTDP also provides mechanisms to meet IPR requirements and quality assurance needs across a wide range of industrial applications, from digital spare‑part warehousing to distributed manufacturing environments.
